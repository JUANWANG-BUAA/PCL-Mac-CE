## Context

上游 `CylorineStudio/PCL.Mac.Refactor` 于 2026-07-22 之后转为私有，官网与 GitHub Pages 站点仓库一并删除。可核实的时间线：

| 时间 | 事件 |
|---|---|
| 2026-07-16 | 上游发布 v1.1.0（#219） |
| 2026-07-22 | 本机最后一次成功匿名 fetch，tip = #219 —— 当时仍公开 |
| 2026-07-24 | **#223** 把非正式"指南"许可证整篇替换为 PCL 官方**《PCL 分发有限许可》**（版权方"成都瓜皮龙科技有限公司"）：只允许传播"原样副本"、禁止"以软件为收费主体"、重度使用条款要求名称不得暗示与 PCL 有关 |
| 2026-08-03 → 08-24 | 继续推进 #224–#248，发布 **v1.1.1**；#246 完善 README 时仍正常指向 Releases 与官网 |
| 2026-08-24 之后 | 仓库转私有、官网与 Pages 站点删除，`meta/PCL.Mac/update.json` 从此 404 |
| 2026-10-07 | 下游镜像仓库合并上游 main 时，tip **仍是** `416cde3`（即 8-24 的 v1.1.1）→ 公开开发已冻结 |

判定依据：API 返回 404 且**无 301 重定向**（排除单纯改名）；组织仍存在但只剩 2 个公开仓库；维护者个人账号下无同名仓库；Pages 域名与 `.github.io` 同时"Site not found"。

**推断（作者无任何公开声明）**：下架与 7-24 的许可证正式化相关。同生态的另一个 macOS 移植版（白枫）同期改名 Bug Craft Launcher 并主动去 PCL 化（剔除旧 PCL 帮助资源、重写关于页划清界限），可作为风向佐证。仓库是**转私有而非删除** —— 2026-10-07 仍有人能从中 merge。

## Decision

以 **v1.1.1** 建立本地基线分支 `dev`（起点 `9c69717`），把公开下游 `AaronXieA/PCL.Mac-XE` 只当作**按需 cherry-pick 的参考源**，不跟随它。

## 校验过程（可复现）

```
本地 origin/main tip        = 6821f549  release: 1.1.0 (#219)   ← 2026-07-22 那次 fetch 的结果
上游 v1.1.1 原版 commit     = 416cde35f47793b23346849019341702340ec576
镜像仓库里的等价重提交      = 9c697174fdacfb56ab03ca7b54333fa130f3ef84
两者 tree                   = dd27019e2e43eec2edbd172cc74294a91d23b2da   ← 完全一致
提交数吻合                  = 本地 155 + 18 = 镜像侧 173
```

原版 SHA `416cde35` **只能按对象经 API 读取，`git fetch` 拿不到**（GitHub 只下发分支可达对象），所以基线只能用重写后的 `9c69717`。

## Alternatives

### A. 跟随 PCL.Mac XE

被否。XE 已于 2026-10-07 改名、更新源迁到第三方域名 `xrst.uk`、并混入它自己的功能（一键更新模组、披风与皮肤选择、回声洞换源）。跟随它等于把产品决策权交给别人的分支，且引入新的单点依赖。

### B. 停在本地已有的 v1.1.0

被否。v1.1.1 含 18 个上游提交，其中有实际影响使用的修复（Forge/NeoForge Maven 镜像 URL 错误、Modrinth 404 处理、macOS 12 设置窗口崩溃缓解、SDKMAN Java 搜索）与实用功能（自定义 JVM 参数、手动添加 Java）。没有理由不拿。

### C. 另起炉灶重写

被否。量化后现状是"可维护"的：18k 行、186 文件、最大文件 435 行（无巨型 View）、Core 83 文件零 UI 依赖、SPM 依赖只有 4 个。重写收益远低于成本。

## Consequences

**正面**

- 拿到上游最后的干净内容（逐字节校验过），无第三方改动污染。
- Core 是 MIT，可自由复用与修改，不受 PCL 那份许可约束。
- 基线在 Xcode 27 上编译通过（0 error），工具链不是障碍。

**负面 / 需要承担**

1. **历史断裂**：`dev` 与 `main` 无共同祖先（`git merge-base` 为空）。从 `xe` remote 合并必须 `--allow-unrelated-histories`；SHA 谱系不再对应上游。
2. **从此自担维护**：上游任何新提交都拿不到。
3. **许可证约束随身**：再分发或改名前必须读《PCL 分发有限许可》（见 U12）。
4. **死依赖不会自愈**：`cylorine.studio` 主域已死、`api.cylorine.studio` 是作者私有单点，见[死依赖与单点](../risk/dead-dependencies.md)。
5. **测试安全网几乎不存在**（11 用例），改鉴权与启动路径要靠手工验证。

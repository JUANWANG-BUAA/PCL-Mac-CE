# ADR-014 独立品牌边界与 macOS 原生视觉

## Context

PCL Mac CE 保留 `PCL` 前缀，是遵守 PCL 许可与衍生作品标识要求；这不代表它与此前的
`PCL.Mac` 产品、维护团队或发行渠道有关联。旧项目公开的 v1.1.1 源码是本仓库的历史代码起点，
其贡献者应得到准确致谢，但当前项目的维护、设计、发行和支持由 JUANWANG-BUAA 独立负责。

早期代码还继承了旧项目的字体、标题图形、导航图标和蓝色主题，容易让用户误以为当前产品仍在
沿用旧项目的界面品牌。Liquid Glass 页面也需要更贴合 macOS 的材质、控件和系统字体。

## Decision

1. **保留 PCL 与必要署名**：产品继续使用 PCL Mac CE 名称，保留根目录 `LICENSE` 全文、
   关于页龙腾猫跃署名和赞助链接、Core 的 MIT 许可证及全部第三方许可。相关来源和致谢如实
   记录于 README、贡献指南、关于页和本 ADR。不得把移除 PCL.Mac 关系误解为删除 PCL 许可归属。
2. **说清 PCL.Mac 的历史关系**：仅将此前公开的 v1.1.1 说明为历史代码起点，并感谢其贡献者；
   当前项目不隶属、不承接此前 PCL.Mac 项目或其维护团队。新增
   `Resources/licenses/PCL-Mac-CE-Baseline-Notice.txt` 作为随源码分发的来源说明。
3. **建立独立的视觉语言**：保留用户确认正确的 PCL Mac CE 应用图标；界面采用青岚绿与中性色、
   macOS 系统字体、SF Symbols 和系统材质。新安装默认使用 Liquid Glass 主题；已有用户的
   明确主题选择保持不变。
4. **清除继承的品牌资产**：移除旧 PCL 字体文件及注册、标题栏旧字标、旧产品头像和过时的
   README 截图，不再从应用界面复用这些资产。截图在重新捕获当前界面后再加入。
5. **保留迁移兼容性**：代码中的旧数据目录名、旧启动参数等仅用于读取老用户数据或兼容历史
   Minecraft 清单，不作为产品品牌、当前路径或对外介绍使用。历史 ADR 仍可在描述当时状态时
   提及旧项目名称。

## Consequences

- 当前产品与 `PCL.Mac` 的差异不再只靠名称解释，应用内视觉、文档和发布身份均由本项目维护。
- 用户仍能从 README、关于页和随源码分发的来源说明中找到 PCL 许可信息及历史代码贡献致谢。
- 旧目录和启动参数字符串仍会在兼容代码中出现，属于迁移行为，不表示恢复上游关系。
- 本 ADR 更新 ADR-012 中关于继续分发旧品牌字体、字标和头像的决定；那些资源已移除。

验证：PCL 许可证与 Core MIT 许可证保留；检查应用源码无旧 PCL 字体/字标/头像资源引用；
Xcode scheme 指向当前工程与 target；运行当前工程构建。
